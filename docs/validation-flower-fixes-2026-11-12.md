# 连续点击、花池与顶部布局修复验证

基于 `codex-fix-flower-bugs` / `35d0323`，针对用户截图中的连续点击延迟、完成订单时阻塞、花池中心聚集/遮挡和顶部花束重叠进行本地修复。

## 改动

- 飞行落点通过实际订单槽父节点换算坐标，包含槽位横向偏移、视口偏移和花束展示缩放。
- 收花事件仍按顺序提交，但不等待花组弹动、新订单入场或旧订单离场。旧花束开始离场时释放槽位，完成时只销毁自己的节点。过早完成新订单时，取消该节点尚未结束的入场动画。
- 完整花束的测量包含尚未收集的花、容器前后层、旋转和入场放大，限制展示宽度和高度；HUD 在安全区内上移，避免计时、进度与花束重叠。
- 普通花按原图尺寸统一缩放为 0.6，保留花种尺寸差异。容量预留使用最终表层尺寸，不随入场缩放、下层缩放或上浮超调变化。补位会跳过放不下的大花，继续寻找能放下的花。
- 初始布局按前后层顺序排布，表层使用旋转轮廓近似避让；点击和补位只调整邻花目标位置，再由帧时间驱动缓动。
- 花池活动边界、输入区域和面积容量连接实际水面尺寸，长屏不再沿用中心 650×650 方形。工具按钮上方预留空间；变更尺寸时保留上浮/打乱的时间进度。
