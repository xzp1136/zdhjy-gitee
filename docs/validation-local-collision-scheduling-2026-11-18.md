## 定位和验证纠正

旧测试误传原始关卡行的 `config.layerMaxCounts`（该属性不存在），回退为 21 / 16 / 16 配置。此前 53 花稳定的结论不能代表真实第二关。真实调用使用 `FlowerRules.layerMaxCounts`，第二关初始分层为 22 / 1 / 39 / 40，上限为 21 / 2 / 40 / 0。测试已改正并明确断言原始数量。

浏览器 `contact-balance-20261118` 的位置记录显示：39 朵水下花持续耗尽检测预算，只有 16 个源轮换处理；线速度接近零，逻辑坐标仍被约束投影来回推移。花池根节点和画布位置保持不变。

真实参数巡检全部 85 关后，又发现第 34 关池边胶囊相交时在两个近似等价的推出方向间切换，由公共接触方向缓存修复。

## 公共实现

- 30 Hz 固定步，单帧最多补 3 步；移除、换层、增长只唤醒附近对象。普通接触传播最多两级，严重互穿可额外唤醒。
- 每步候选对上限：前景 1,024 / 中层 384 / 水下 2,048；精细几何调用额度：1,024 / 256 / 1,536。三个层互不抢预算。热接触源上限统一为 48，覆盖现有关卡最大可见层密度；只有空闲零散背景对象分批、降频检查。
- 每轮累计并平均接触修正后统一应用。普通游戏层若预算未完成，丢弃该轮不完整的修正，保留之前完整轮次，避免换一边推。预算按实际几何调用计数。
- 近似等价的分离方向保留上次方向；旧方向的投影深度超过当前最小值加上 `max(0.02 米, 最小深度×5%)` 才换方向。移除、换层、重新激活清除相关缓存，不保留已移除对象引用。
- 接触组协调休眠；投影本身不算主动扰动，微小残余修正不再永久重置休眠计时。上一接触组大小参与容差判断，避免容差随遍历次序切换。
- 单对边缘重叠允许较小包围直径的 0.5%，封顶 0.006 米；密集组允许 2%，封顶 0.06 米；另有 0.0025 米数值容差。仍保留明显互穿的独立几何间距回归。
- 只在缩放、角度改变时重建局部轮廓；平移更新 AABB 并惰性同步世界坐标。独立显示缓冲以 0.05 秒时间常数跟随，不回写碰撞状态。

本轮未调整花朵数量、美术尺寸、水池布局、点击轮廓及原有升层补花机制。
