2026-11-08，Creator 3.8.7 工程 `ZDHJY`，场景 `FlowerGame`。最新微信构建为 `zdhjy-wechat-1794139887481-7b7285`，AppID `wx3ef66f850d873a67`，输出目录 `build/wechatgame/`。此前代理连接问题由用户反馈已恢复，本轮没有修改系统代理。

## 修复内容

- 将固定 `SHOW_ALL` 改为按屏幕比例选择固定宽度或固定高度，画面使用整个渲染表面。首页和 loading 背景等比覆盖屏幕，顶部内容避开安全区与微信胶囊，底部导航避开手势区且底色延伸到底边。
- 关卡顶部、花池、道具栏使用独立布局锚点；木盆、水面遮罩、水纹与横板随视口延伸。弹窗遮罩覆盖全屏，内容在安全区内居中，布局缩放与开合动画分离。调整窗口尺寸不重新开局或重置存档。
- 连续点花加入去重队列，接受点击后立即播放原点击声并请求短震动；规则结算和落花动画仍依次执行。暂停清除未执行点击，当前花落稳后停止；胜负已确定时先完成结算，防止通过暂停返回主页而跳过奖励保存。
- 震动读取已有的 `zdhjy.vibrate` 设置，微信调用 `wx.vibrateShort({type:'light'})`，90 ms 内合并反馈。关闭开关、不支持接口或调用失败均不阻断游戏。浏览器仅在支持时请求 12 ms 震动。

安全区直接使用 Cocos 返回的设计坐标，不重复乘设备像素比；微信胶囊从逻辑像素换算到相同坐标。背景可以延伸到安全区外，交互内容保留在安全区内，参见 [Cocos SafeArea 文档](https://docs.cocos.com/creator/3.8/api/en/class/SafeArea)。
